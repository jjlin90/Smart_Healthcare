# BERT 多标签阈值复测（2026-10-12）

当前模型的十个意图继续使用 **0.5**。这是本轮验证集搜索中的并列最优设置，逐类阈值没有带来提升；不是未经验证沿用默认值，也不能宣称为真实请求上的唯一最优阈值。项目实际加载的逐类阈值已检查，仍全部为 0.5，`INTENT_BERT_UNCERTAINTY_MARGIN` 保持 0.08。

## 方法和证据

本轮重新加载本地 v4 权重并实际推理 2,380 条样本，而非只重算历史报告。权重、分词器及原阈值文件与既有模型指纹吻合。

- 640 条验证样本用于选择阈值；1,340 条测试样本和 400 条挑战样本仅在选择冻结后用于复核。
- 3,100 条训练数据只参与重复检查，不用于阈值选择。四个集合按 `strip().casefold()` 检查，任意两集合的重复文本数均为 0。模板相似性仍存在，这不证明语义独立或真实泛化。
- 统一阈值搜索包含 0 到 1、步长 0.01 的 101 个值，以及验证分数的所有不同断点，共 6,492 个候选。对 `score >= threshold` 的决策，这些断点覆盖验证集上统一阈值可产生的全部预测集合。
- 同时逐类搜索全部分数断点和网格值，以各类 F1 最高为目标；并列时优先接近该类当前阈值。
- 在当前配置、统一阈值最优配置、逐类 F1 最优配置之间，以验证集 Macro-F1 优先，依次用完整集合匹配率和 Micro-F1 打破并列；指标仍相同则保留当前配置。没有用测试或挑战标签选阈值。

## 冻结阈值后的复核

| 集合 | 样本数 | 集合匹配率 | Micro-F1 | 错误增加标签数 | 漏标签数 |
|---|---:|---:|---:|---:|---:|
| 独立合成测试 | 1,340 | 100% | 100% | 0 | 0 |
| 挑战集整体 | 400 | 87% | 94.6108% | 16 | 47 |
| 挑战集多意图 | 250 | 97.2% | 99.2951% | 0 | 7 |
| 挑战集单意图（否定、模糊等） | 100 | 60% | 70.1754% | 11 | 40 |
| 挑战集域外 | 50 | 90% 空集合拒识 | 不适用 | 5 | 0 |

域外真值为空，Micro-F1 的零分母按实现返回 0；这里应看空集合拒识率，不能把 0 解读为全部拒识失败。上述数字来自 **BERT 单独评测**，不是范围守卫或完整三路融合的整体准确率。相对当前 0.5 配置，测试及挑战指标变化均为 0。

否定、模糊表达和域外误识仍是已有短板。阈值搜索结果不证明这些问题已解决。后续应增加独立标注、与实际工作台表达接近的验证数据，再逐类重新选择阈值；本轮不据挑战集反向调参。

## 项目使用状态与复现

`IntentClassifier._thresholds()` 已核验十类均为 0.5。加载顺序为全局默认值 → 模型目录阈值文件 → 显式逐类配置覆盖。此次没有必要改写权重、模型阈值文件或 `.env`；保留已验证的最优候选可以避免破坏历史指纹。融合规则、0.08 不确定性边界和 MCP/A2A 业务链未改变。

```powershell
python scripts/calibrate_intent_bert.py `
  --output artifacts/bert_threshold_search_new.json `
  --cache-dir artifacts/bert_threshold_search_new `
  --batch-size 16
python -m pytest tests/test_bert_threshold_calibration.py tests/test_intent_fusion.py -q
python scripts/check_config.py
```

校准命令只出报告，不自动写入模型或配置，报告已存在时拒绝覆盖。重新运行会重新加载当前模型推理；若模型已更换，结果可能不同。报告同时保存实际生效阈值、数据和模型 SHA-256、样本数、逐类搜索范围及冻结后的复核指标。

本轮 61 项定向测试通过；用已有 `scripts.intent_metrics` 和 scikit-learn 独立核对三集合指标，并逐项核对 101 个验证网格值。核心配置检查及模型/验证数据指纹检查均通过。

[可共享评测摘要](../evaluation/bert_threshold_search_20261012_summary.json)保留完整验证网格和各类最优候选范围。本地完整报告 `artifacts/bert_threshold_search_20261012.json` 与预测分数缓存位于忽略目录，不覆盖旧评测或旧模型清单。
