## 验证

本轮完整自动化回归 **170 项通过**，比核查前的 143 项新增 27 项回归。存在 LangChain MCP beta 与 Starlette WSGI 弃用警告。依赖一致性、候选 Python 语法及 Git 上传前敏感内容检查通过。

本轮环境中观察到沙箱内最小 `asyncio.run(asyncio.sleep(0))` 阻塞，原因尚未定位；异步回归在获得权限后于沙箱外执行，数据库和协议测试仍使用隔离测试环境。该观察不作为已确认的项目业务缺陷或环境根因。

工作台使用明确的非临床测试数据和 HTTP 读请求替身验证，不登录真实员工或调用真实医院。浏览器环境为本机隔离入口，桌面 1440×1100 与手机 390×844；页面标题、非空内容、错误状态、控制台及患者切换交互均已检查。原生测试先复现旧输入串到新患者，再验证修复。浏览器无应用错误；截图与详细日志保存为本地产物。

本轮未重跑 BERT/BGE 历史效果、真实医院读写、完整链路压测或目标集群部署；历史指标仍保留其数据集、时间与分母。
